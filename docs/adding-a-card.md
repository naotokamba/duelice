# カードを足す手順

カードの知識は `src/game/cards.ts` の定義表に集めてあります。ルール本体の `rules.ts`、画面の組み立ての `compose.ts`、CPU は定義表を読むだけなので、既存の性質で表せるカードなら定義表に書けば追従します。

## 1. 型に名前を足す

`src/game/types.ts` の `CardId` にカードの名前を、`ActionKind` に行動の名前を足します。雷槍の詠唱と発動のように、1枚のカードが複数の行動を持つこともあります。

足した時点で `pnpm typecheck` が落ちます。`CARD_DEFS` と `ACTION_DEFS` が `Record` なので、定義の書き忘れは型エラーになります。

## 2. 定義表に書く

`src/game/cards.ts` に書きます。

- `CARD_DEFS` には名前と説明文を書きます。説明文は画面とルール説明にそのまま出ます
- `ACTION_DEFS` には行動の性質を書きます
- `CARD_ORDER` に画面での並び順を足します

使える性質は次のとおりです。

| 性質 | 意味 |
| --- | --- |
| `dice` | 置けるダイスの個数。複数の個数を許すなら `[1, 2]` |
| `step` | 使えるステップを限定する |
| `sameValues` | 置くダイスが全て同じ目である必要がある |
| `power` | 攻撃の威力。目から計算する |
| `piercing` | 障壁を無視する |
| `guard` | 受ける攻撃を減らす量 |
| `reflects` | 受ける攻撃を無効化して返す |
| `chant` / `needsCharge` | 詠唱と、詠唱が保たれたときだけ使える発動 |
| `done` | 攻撃以外の行動を公開したときの文 |

既存の性質で表せない仕組みが要るときだけ、`ActionDef` に性質を足し、`rules.ts` の `stepDamage` か `resolveStep` でその性質を処理します。カードの名前で分岐する書き方はしません。

## 3. 仕様表に行を足す

`src/game/cards.test.ts` の `SPEC` に、新しいカードが他のカードとぶつかったときの期待ダメージを書きます。少なくとも次の相手との組み合わせを書いてください。

- 何もしない相手
- 障壁
- 反射
- 同じカード同士

一行書くと、席を入れ替えた場合も自動で検査されます。行の無い行動があると「全ての行動が仕様表に一度は登場する」のテストが落ちます。

## 4. 色を決める

`src/styles.css` に `--新しいカード名` の色と `.card-新しいカード名` を足します。ライトとダークの両方に足します。足し忘れても既定の色で表示されます。

## 5. 確かめる

```sh
pnpm check          # 型、lint、全テスト、カバレッジ
pnpm test:balance   # バランスの記録。数字が変わるはず
```

`pnpm test:balance` は、つよいCPUが一ステップ目に各行動を選ぶ頻度などを記録と比べます。カードを足せば数字は変わるので、変化を見て意図どおりなら `pnpm test:balance -u` で記録を更新し、差分をコミットに含めます。記録の差分がそのままバランス変更の説明になります。

設計の原則に照らして、次も見てください。

- 新しいカードの頻度が0に近いなら、選ぶ理由が無いカードになっている
- 読み合いが起きない局面の割合 `pureStrategyRate` が大きく増えていないか
- 既存のカードの頻度が極端に下がっていないか

## 自動で検査されること

カードを足すと、何も書かなくても次の性質が乱数で大量に検査されます。`src/game/invariants.test.ts` にあります。

- 列挙された合法手は全て合法で、合法手の漏れも重複も無い
- ダメージは負にならない。攻撃しない側は相手を削らない
- 席を入れ替えると結果も入れ替わる
- HPはダメージ分だけ減り、使ったダイスとカードが記録される
- 勝敗がHPと一致する。元の状態を書き換えない
- 乱数の手で最後まで対局しても規則が壊れない。同じ種なら同じ対局になる

画面からの組み立ても `compose.test.ts` で検査されます。全ての行動が画面の操作で作れること、合法手が全て画面から組み立てられることを確かめます。

CPU は `cpu.test.ts` で、つよいの戦略が行列ゲームの均衡になっていることを確かめます。
