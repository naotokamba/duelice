# Duelice

3個のダイスを振り、互いに見えている目で読み合う、魔術師の決闘ゲームの試作です。CPUと対戦できるほか、オンライン対戦も試しに出しています。

https://duelice.naotokamba.com で遊べます。ルールはゲームの中の「?」から読めます。

## 手元で動かす

```sh
pnpm install
pnpm dev
```

ブラウザで http://localhost:3000 を開きます。

オンライン対戦も同じ開発サーバで試せます。ブラウザのウィンドウを二つ開き、一つはシークレットウィンドウにして、それぞれ「オンライン対戦」から名前を入れてロビーへ進みます。片方で部屋を作り、出た4桁の合言葉を、もう片方で入れて入ります。部屋とロビーは開発サーバの中の Durable Object が持ち、`.wrangler/state` に残ります。

開発に加わるときは [CONTRIBUTING.md](CONTRIBUTING.md) を読んでください。
